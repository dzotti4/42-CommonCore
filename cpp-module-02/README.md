# C++ Module 02

## Description

Ad-hoc polymorphism, operator overloading and the Orthodox Canonical Form, with a fixed-point number class.

Exercises: ex00 My First Class in Orthodox Canonical Form · ex01 Towards a more useful fixed-point number class · ex02 Now we're talking.

Written in C++98 and compiled with `-Wall -Wextra -Werror -std=c++98`.

## Instructions

```bash
make        # in each exercise folder (ex00, ex01, …)
./<program>
```
