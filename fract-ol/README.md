# fract-ol

## Description

A fractal explorer built with the MiniLibX graphics library. It renders the Mandelbrot set and Julia sets, with zoom and movement.

## Instructions

```bash
make
./fractol mandelbrot
./fractol julia -0.8 0.156
```

Needs the MiniLibX (Linux) to build.

## What I learned

- Complex numbers and the escape-time algorithm
- Drawing pixels and handling keyboard and mouse events
