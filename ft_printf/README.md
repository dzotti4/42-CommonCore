# ft_printf

## Description

A re-implementation of `printf`. Supports the conversions `%c`, `%s`, `%p`, `%d`, `%i`, `%u`, `%x`, `%X` and `%%`, and returns the number of printed characters.

## Instructions

```bash
make         # builds libftprintf.a
```
