# push_swap

## Description

Sorts a list of integers using two stacks (a and b) and a limited set of operations (`sa`, `pb`, `ra`, `rra`, …), with as few operations as possible. Small inputs use a dedicated sort; larger inputs use radix sort.

## Instructions

```bash
make
./push_swap 3 2 5 1 4
```

The program prints the operations, one per line. Invalid input (non-numbers, duplicates, overflow) prints `Error`.
